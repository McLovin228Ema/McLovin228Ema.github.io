Пусть требуется разработать информационную систему для автоматизации учета работы небольшой флотилии рыболовных катеров. Система должна предусматривать режимы ведения реестра судов, регистрации выходов на лов и учета пойманной рыбы. Внутри системы каждый катер характеризуется следующими параметрами:

· название катера;
· тип катера;
· водоизмещение;
· дата постройки.

Фирма регистрирует каждый выход на лов. Каждый выход на лов характеризуется следующими параметрами:

· название катера;
· дата выхода;
· дата возвращения;
· список членов команды с указанием их должностей (капитан, боцман и т.д.).

Учет пойманной рыбы ведется для каждого выхода на лов. Для улова фиксируются следующие сведения:

· вес пойманной рыбы (учитывается отдельно по сортам, например, треска);
· качество рыбы (оценка: отлично, хорошо, удовлетворительно, неудовлетворительно).

Предусмотреть следующие ограничения на информацию в системе:

1. Каждый катер должен иметь уникальное название.
2. Учет веса пойманной рыбы ведется отдельно по сортам.
3. Качество рыбы оценивается по фиксированной шкале (отлично, хорошо, удовлетворительно, неудовлетворительно).

С данной информационной системой должны работать следующие группы пользователей:

· администрация флота;
· капитаны/бригадиры;
· аналитики.

При работе с системой администрация флота должна иметь возможность решать следующие задачи:

1. Принимать новые катера и регистрировать их в реестре флотилии.
2. Регистрировать каждый выход на лов с указанием названия катера, даты выхода и даты возвращения.
3. Вести учет членов команды с указанием их должностей (капитан, боцман и т.д.).
4. Просматривать сводные данные по уловам за период.

При работе с системой капитан/бригадир должен иметь возможность решать следующие задачи:

1. Вносить данные о весе пойманной рыбы отдельно по сортам (например, треска).
2. Указывать качество пойманной рыбы (отлично, хорошо, удовлетворительно, неудовлетворительно).

Аналитик должен иметь возможность получать сведения о количестве и качестве выловленной рыбы за определенный период, а также данные о выходах на лов конкретных катеров.
